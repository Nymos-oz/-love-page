# Страница для нас

Это статический сайт для GitHub Pages. Все фотографии и звуковая дорожка лежат рядом с `index.html`, поэтому сайт не зависит от локального сервера, внешнего музыкального сервиса или сборки проекта.

## Публикация на GitHub Pages

1. Создайте новый **публичный** репозиторий на GitHub.
2. Загрузите в корень репозитория `index.html`, файл `.nojekyll` и папку `assets` целиком.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажмите **Save**.
5. Подождите, пока GitHub Pages опубликует сайт. Адрес будет иметь вид `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

Сайт на GitHub Pages доступен через HTTPS с телефона, компьютера и из других стран. Адрес `localhost` работает только на устройстве, где запущен сервер.

## Важно о приватности

На публичной странице GitHub Pages фотографии и сайт доступны всем, у кого есть ссылка. Перед публикацией убедитесь, что обеим комфортно делиться этими фотографиями.
